    Create `DefaultRocksDbStorage.java` (per D-03 — Default prefix for application implementations):
    - Implements `RocksDbStorage` AND `SmartLifecycle`
    - `@Service`, `@Slf4j`, `@RequiredArgsConstructor`
    - Injected: `StorageConfiguration config`, `MeterRegistry meterRegistry` (for RocksDB latency timers — D-15)
    - Field: `private volatile boolean running = false;`
    - Field: `private RocksDB db;`
    - Field: `private DBOptions dbOptions;`
    - Field: `private final Map<RocksDbColumnFamily, ColumnFamilyHandle> cfHandleMap = new EnumMap<>(RocksDbColumnFamily.class);`
    - Field: `private final List<ColumnFamilyHandle> allHandles = new ArrayList<>();` (includes default CF handle)

    `getPhase()` returns `Integer.MIN_VALUE` (starts first — per D-07, research Pattern 1)

    `start()`:
    1. Call `RocksDB.loadLibrary()` (MUST be first — research anti-pattern: never call lazily)
    2. Create directory if not exists: `Files.createDirectories(Path.of(config.getPath()))`
    3. Build column family descriptors: default CF + all `RocksDbColumnFamily` enum values
    4. Create `DBOptions` with `setCreateIfMissing(true)` and `setCreateMissingColumnFamilies(true)`
    5. Open ALL column families in a SINGLE `RocksDB.open(dbOptions, path, cfDescriptors, cfHandlesList)` call (research anti-pattern: never open CFs separately)
    6. Map handles: allHandles[0] = default, then allHandles[1..4] mapped to enum values in order
    7. Initialize schema_version: if `get(METADATA, "schema_version")` returns null, `put(METADATA, "schema_version", "1")`
    8. Set `running = true`
    9. Log: `"RocksDB opened at {} with {} column families", config.getPath(), RocksDbColumnFamily.values().length`

    `stop()`:
    1. Log: `"Closing RocksDB..."`
    2. Close ALL ColumnFamilyHandle objects FIRST (per D-06, research Pitfall 3 — handles BEFORE database)
    3. Close `db` (flushes memtable)
    4. Close `dbOptions`
    5. Set `running = false`
    6. Log: `"RocksDB closed"`

    `put(cf, key, value)`:
    1. Get handle from `cfHandleMap.get(cf)` — throw `IllegalStateException("RocksDB not running")` if not running
    2. `db.put(handle, key.getBytes(UTF_8), value.getBytes(UTF_8))`
    3. Wrap in Timer for `rocksdb.write.latency` metric with tag `cf=cf.getName()`

    `get(cf, key)`:
    1. Get handle, check running state
    2. `byte[] value = db.get(handle, key.getBytes(UTF_8))`
    3. Return `value == null ? null : new String(value, UTF_8)`
    4. Wrap in Timer for `rocksdb.read.latency` metric with tag `cf=cf.getName()`

    `delete(cf, key)`:
    1. Get handle, check running state
    2. `db.delete(handle, key.getBytes(UTF_8))`
