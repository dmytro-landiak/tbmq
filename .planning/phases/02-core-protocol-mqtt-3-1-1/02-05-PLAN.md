    **Create `DefaultLastWillService`** (`@Service`, `@Slf4j`):
    Per RESEARCH Pattern 9: `ConcurrentHashMap<UUID, WillMessage>` keyed by session ID (not client ID).

    ```java
    @Service
    @Slf4j
    public class DefaultLastWillService implements LastWillService {
        private final ConcurrentHashMap<UUID, WillMessage> willMessages = new ConcurrentHashMap<>();

        @Override
        public void storeWill(UUID sessionId, WillMessage willMessage) {
            willMessages.put(sessionId, willMessage);
            log.debug("Stored LWT for session {} on topic '{}'", sessionId, willMessage.getTopicName());
        }

        @Override
        public Optional<WillMessage> removeWill(UUID sessionId) {
            WillMessage will = willMessages.remove(sessionId);
            if (will != null) {
                log.debug("Retrieved LWT for session {} (topic: '{}')", sessionId, will.getTopicName());
            }
            return Optional.ofNullable(will);
        }

        @Override
        public void removeWillWithoutDelivery(UUID sessionId) {
            WillMessage removed = willMessages.remove(sessionId);
            if (removed != null) {
                log.debug("Removed LWT for session {} without delivery (topic: '{}')", sessionId, removed.getTopicName());
            }
        }
    }
    ```

    Key design per RESEARCH Pattern 9:
    - Store: at CONNECT time if will flag is true
    - Remove without delivery: ON_DISCONNECT_MSG (clean), ON_CONFLICTING_SESSIONS (takeover)
    - Remove with delivery: ON_KEEP_ALIVE, ON_CHANNEL_CLOSED, ON_ERROR, etc. (any reason where `allowsLastWillOnDisconnect()` returns true)
    - Keyed by UUID sessionId, not clientId — this handles takeover correctly: old session has different sessionId

    Create a private method `processDisconnect(DisconnectReasonType reasonType)`:
    ```java
    private void processDisconnect(DisconnectReasonType reasonType) {
        if (sessionCtx.getState() == SessionState.DISCONNECTED) return; // already disconnected
        sessionCtx.setState(SessionState.DISCONNECTING);

        // LWT handling
        if (reasonType.allowsLastWillOnDisconnect()) {
            lastWillService.removeWill(sessionCtx.getSessionId()).ifPresent(will -> {
                // Deliver LWT as a regular publish
                deliverToSubscribers(will.getTopicName(), will.getQos(), will.getPayload(), will.isRetain());
                // Handle retained flag on LWT
                if (will.isRetain()) {
                    if (will.getPayload().length == 0) {
                        retainedMsgService.clearRetainedMessage(will.getTopicName());
                    } else {
                        retainedMsgService.setRetainedMessage(will.getTopicName(),
                            RetainedMsg.builder().topicName(will.getTopicName()).qos(will.getQos()).payload(will.getPayload()).build());
                    }
                }
            });
        } else {
            // Clean disconnect or takeover — remove will without delivery
            lastWillService.removeWillWithoutDelivery(sessionCtx.getSessionId());
        }

        // Cleanup
        subscriptionRegistry.removeAllSubscriptions(clientId);
        sessionRegistry.removeSession(clientId);
        sessionCtx.setState(SessionState.DISCONNECTED);

        // Close channel if still open
        if (sessionCtx.getChannel().channel().isActive()) {
            sessionCtx.getChannel().close();
        }

        // Stop actor
        ctx.stop(ctx.getActorId());
    }
    ```
