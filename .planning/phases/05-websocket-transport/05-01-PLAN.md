    **Part A: Create AbstractServerBootstrap (per D-02)**

    Create `lightweight/src/main/java/org/thingsboard/mqtt/broker/lightweight/server/AbstractServerBootstrap.java`:

    Package: `org.thingsboard.mqtt.broker.lightweight.server`

    This is an abstract class implementing `SmartLifecycle`. It encapsulates the common Netty server lifecycle shared by TCP, TLS, WS, and WSS bootstraps. Extract the duplicated logic from the current `MqttTcpServerBootstrap` and `MqttSslServerBootstrap`.

    Class structure:
    - `@Slf4j` annotation
    - Fields: `private final NettyConfiguration nettyConfig` (injected by subclass constructor), `private EventLoopGroup bossGroup`, `private EventLoopGroup workerGroup`, `private Channel serverChannel`, `private volatile boolean running = false`
    - Abstract methods:
      - `protected abstract int getPort()` — the port to bind to
      - `protected abstract ChannelInitializer<SocketChannel> getChannelInitializer()` — the pipeline initializer
      - `protected abstract String getServerName()` — for log messages (e.g., "MQTT TCP", "MQTT TLS", "MQTT WS", "MQTT WSS")
    - Concrete methods:
      - `start()`: Epoll/NIO detection (same logic as current TCP bootstrap), boss/worker group creation using `nettyConfig.getBossThreads()` and worker thread calculation (`workerThreads > 0 ? workerThreads : availableProcessors()`), `ServerBootstrap` configuration with `SO_BACKLOG=1024`, `SO_KEEPALIVE=true`, `ALLOCATOR=PooledByteBufAllocator.DEFAULT`, bind to `getPort()`, set `running=true`, log `"{serverName} started on port {localPort} (transport: {epoll/nio})"`
      - `stop()`: log stopping, close `serverChannel.close().awaitUninterruptibly()`, `bossGroup.shutdownGracefully(0, 5, SECONDS).awaitUninterruptibly()`, `workerGroup.shutdownGracefully(0, 5, SECONDS).awaitUninterruptibly()`, set all to null, `running=false`, log stopped
      - `isRunning()`: returns `running`
      - `getLocalPort()`: returns `serverChannel == null ? -1 : ((InetSocketAddress) serverChannel.localAddress()).getPort()`
      - `getPhase()`, `isAutoStartup()` — remain abstract (NOT provided by base, each subclass overrides)

    NOTE: `getPhase()` and `isAutoStartup()` are SmartLifecycle methods with defaults (0 and true). The abstract base does NOT override them — each concrete subclass provides its own. The base only implements `start()`, `stop()`, `isRunning()`, and `getLocalPort()`.

    Constructor: `protected AbstractServerBootstrap(NettyConfiguration nettyConfig)` — stores `this.nettyConfig = nettyConfig`.
