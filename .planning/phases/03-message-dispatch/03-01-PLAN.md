<objective>
Copy and adapt TBMQ's battle-tested wildcard subscription trie and retained message trie into the lightweight module, establishing the core data structures for Phase 3 wildcard topic matching.

Purpose: These two tries are the algorithmic foundation for INFR-01 (in-process dispatch). The subscription trie replaces the Phase 2 ConcurrentHashMap exact-match lookup with O(topic-depth) wildcard matching. The retained message trie enables wildcard retained message delivery on subscribe. Both are copied from TBMQ with StatsManager dependencies removed and Guava replaced with JDK equivalents.

Output: Two trie implementations with interfaces, supporting constants, ValueWithTopicFilter data class, and comprehensive unit tests proving wildcard correctness and $SYS/ exclusion.
</objective>
