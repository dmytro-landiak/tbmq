    - `evict(String clientId)`: Remove clientId entry from `publishAuthMap`

    **10. Create `DefaultLightweightAuthService`** (per D-04, D-05, D-06, D-07):
    - `@Service @Slf4j @RequiredArgsConstructor`
    - Inject: `LightweightCredentialService credentialService`, `ObjectMapper objectMapper`, `BCryptPasswordEncoder passwordEncoder`, `AuthorizationRuleService authorizationRuleService`
    - `@Value("${tbmq.security.anonymous-enabled:false}") private boolean anonymousEnabled;`
    - `authenticate(username, password, sslHandler)`:
      1. If `sslHandler != null`: try SSL auth first (extract peer cert CN, lookup credential, parse SSL auth rules). Return `AuthResult.success(patterns)` on match.
      2. If `username != null && !username.isEmpty()`: try basic auth — lookup `credentialService.findByCredentialId(username)`, verify type is BASIC, deserialize `credentialValue` as `BasicMqttCredentials`, call `passwordEncoder.matches(password, creds.getPassword())`. On match, return `AuthResult.success(authorizationRuleService.parseAuthorizationRule(creds))`.
      3. If no credentials provided and `anonymousEnabled` is true: return `AuthResult.success(Collections.emptyList())` (empty patterns = bypass ACL per D-12).
      4. If no credentials and `anonymousEnabled` is false: return `AuthResult.failure("Anonymous connections not allowed")`.
      5. If credentials present but invalid: return `AuthResult.failure("Bad username or password")`.

      6. Log `"Default credentials installed: username=tbmq"`
